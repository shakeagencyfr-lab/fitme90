# Photos de la landing

La page d'accueil affiche un dégradé sombre par défaut. Pour ajouter tes vraies
photos, dépose-les ici avec **exactement** ces noms de fichier :

| Fichier            | Emplacement sur la page                     | Format conseillé            |
| ------------------ | ------------------------------------------- | --------------------------- |
| `hero.jpg`         | Fond du grand titre (haut de page)          | paysage, ~1600×900, sombre  |
| `salle.jpg`        | Encadré « Analyse IA de ta salle »          | paysage, ~1200×900          |

- Si un fichier est absent, le dégradé sombre s'affiche seul — **aucune image cassée**.
- Formats acceptés : `.jpg` (recommandé pour les photos). Garde le poids sous ~300 Ko
  par image pour la vitesse sur mobile.
- Le contenu passe déjà en blanc sur fond sombre : choisis des photos plutôt
  sombres/contrastées, ou elles seront de toute façon assombries par le dégradé.

Une fois les fichiers déposés et poussés, ils apparaissent automatiquement —
il n'y a rien à changer dans le code.
